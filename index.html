Guía de creación de proyecto con Entity Framework

  • 5 min
  • ⚡ Intermedio

Esta guía te mostrará paso a paso cómo configurar un proyecto .NET Core con Entity Framework Core, MySQL y Swagger para crear una API RESTful completa. Sigue cada paso cuidadosamente.

📌 Requisitos previos: Tener instalado .NET Core SDK 2.2+, MySQL Server, y un editor como Visual Studio o VS Code.

1

Instalación de Pomelo.EntityFrameworkCore.MySql

Primero, instala el paquete necesario para conectar Entity Framework con MySQL:

dotnet add package Pomelo.EntityFrameworkCore.MySql --version 2.2.0

O desde la consola de NuGet:

Install-Package Pomelo.EntityFrameworkCore.MySql -Version 2.2.0
2

Scaffolding de la Base de Datos

Ejecuta el siguiente comando para generar los modelos a partir de tu base de datos existente:

Scaffold-DbContext "server=localhost;database=teamworkbd;user=root;password=;" Pomelo.EntityFrameworkCore.MySql -OutputDir Models -Context DbteamworkbdContex

💡 Nota: Asegúrate de que la base de datos teamworkbd exista en tu servidor MySQL antes de ejecutar este comando.

3

Anular la conexión en el Contexto

Después del scaffolding, ve al archivo DbteamworkbdContex.cs y comenta o elimina la configuración de conexión en el método OnConfiguring:

//            if (!optionsBuilder.IsConfigured)
//            {
//#warning To protect potentially sensitive information...
//                optionsBuilder.UseMySql("server=localhost;database=teamworkbd;user=root;password=;");
//            }

Esto es importante porque la conexión se configurará desde appsettings.json en lugar de estar hardcodeada.

4

Instalación de Swagger

Para documentar tu API, instala Swashbuckle:

dotnet add package Swashbuckle.AspNetCore.Swagger --version 2.2.0

O desde NuGet:

Install-Package Swashbuckle.AspNetCore.Swagger -Version 2.2.0
5

Configuración de appsettings.json

Agrega la cadena de conexión a tu archivo appsettings.json:

{
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "DefaultConnection": "server=localhost;database=teamworkbd;user=root;password=;"
  }
}
6

Configuración de Startup.cs

Configura los servicios en el método ConfigureServices de Startup.cs:

using TEAMWORK.Models;
using Microsoft.EntityFrameworkCore;
using Swashbuckle.AspNetCore.Swagger;

public void ConfigureServices(IServiceCollection services)
{
    // Cadena de conexión con parámetros requeridos
    services.AddDbContext<DbteamworkbdContex>(options => 
        options.UseMySql(Configuration.GetConnectionString("DefaultConnection")));
    
    services.AddMvc().SetCompatibilityVersion(CompatibilityVersion.Version_2_2);
    
    // Configuración de Swagger
    services.AddSwaggerGen(c =>
    {
        c.SwaggerDoc("v1", new Info { Title = "TEAMWORK API", Version = "v1" });
    });
}

public void Configure(IApplicationBuilder app, IHostingEnvironment env)
{
    if (env.IsDevelopment())
    {
        app.UseDeveloperExceptionPage();
    }
    
    // Habilitar Swagger
    app.UseSwagger();
    app.UseSwaggerUI(c =>
    {
        c.SwaggerEndpoint("/swagger/v1/swagger.json", "TEAMWORK API V1");
    });
    
    app.UseMvc();
}
7

Creación de Controladores API

Sigue estos pasos para crear los controladores:

📋 Pasos detallados para crear controladores

  1. Haz clic derecho en la carpeta Controllers
  2. Selecciona Agregar → Controlador
  3. Elige la opción "Controlador de API con acciones que usan Entity Framework"
  4. Selecciona el modelo correspondiente
  5. Selecciona DbteamworkbdContex como contexto de datos
  6. Haz clic en Agregar

Verificación de Swagger

Una vez completada la configuración, ejecuta el proyecto y navega a:

https://localhost:5001/swagger

Deberías ver la interfaz de Swagger con todos tus endpoints documentados automáticamente.

✅ Resumen de paquetes instalados:

  • Pomelo.EntityFrameworkCore.MySql (2.2.0)
  • Swashbuckle.AspNetCore.Swagger (2.2.0)
  • Microsoft.EntityFrameworkCore (dependencia incluida)
